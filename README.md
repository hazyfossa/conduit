# conduit
Conduit - это ПО, позволяющее упаковывать веб-приложения любой сложности в `.exe` файлы. Вы предоставляете папку со статичными ресурсами, а на выходе получаете исполняемый файл.

Программы, упакованные с помощью conduit, не требуют создания установщика и являются портативными. 

Используемый формат ресурсов также поддерживает zero-copy кодирование. Это означает, что conduit никогда не создаёт временных папок, не копирует данные, не оставляет "мусора" в системе пользователя.

# сборка приложения
Запустите conduit-builder.exe, введите путь к папке с ресурсами, выберите необходимые настройки, нажмите старт. Готово, вы великолепны!
